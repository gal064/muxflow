Remote-first tmux IDE for coding agents

Cross-device notifications for Claude Code and Codex, multi-host SSH connections, seamless pasting, a file explorer, uploads and downloads, and a Git client.

features

  1. 01Remote firstBuilt to work on remote machines over SSH.
  2. 02Multi-hostWorkspaces and agents from several SSH hosts in one sidebar, each marked with its host.
  3. 03Native copy and pastePaste or drag screenshots and files from your laptop into a remote pane. Claude Code and Codex see them as if they were local.
  4. 04File explorerBrowse, edit and download files on the remote machine, right next to the terminal.
  5. 05Git clientDiff, stage, commit and push without leaving Muxflow.
  6. 06tmux basedYour processes keep running even when you close Muxflow.
  7. 07Agent statusAgent statuses and notifications on both desktop and mobile, for Claude Code and Codex.
  8. 08Mobile appAndroid and iOS (coming soon).
  9. 09Open sourceMIT licensed.
