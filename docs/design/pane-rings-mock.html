Stronger grey

Light #a1a1aa, dark #5c6370, against the chrome_hairline divider. In a two-pane split the darker line says only that a split exists, not which side is active; the blinking cursor and the composer's focus are the only remaining cues. If that's enough, the code gets simpler: the ring code goes, and only the divider's colour depends on the active pane.
