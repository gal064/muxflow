Muxflow Automations Mocks

Desktop mocks for scheduled agent runs. The helper on each host owns the automations and runs them. Every run opens a new tab in a single automation workspace on that host. The examples below are made up.

What runs
  • Cron only, in the host's local time, with a plain-English reading and the next three runs below it. There are no presets or time zones.
  • Custom command is used exactly as typed. Muxflow only adds the quoted prompt at the end, so cx --print becomes cx --print '…'. Making that command work is up to you.
  • The command is typed into an interactive shell in the new tab, so aliases and shell functions like cx work.
