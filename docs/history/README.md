# Historical plans

The documents in [plan](./plan/) record requirements, design decisions, and
implementation plans from earlier stages of Muxflow. They are kept for context,
not as current build instructions. Some paths and commit IDs refer to the
original development history and may not resolve in the rewritten public
history. Personal examples were neutralized, and the Android package name uses
the current public namespace.

For current instructions, use the root [README](../../README.md),
[setup](../setup.md), and [release guide](../release.md). The historical
[mobile design](../mobile/design.md), [decisions](../mobile/decisions.md), and
[voice mode plan](../mobile/voice-mode-plan.md) are also available.
