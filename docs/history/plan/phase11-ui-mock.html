Phase 11 · tmux Agent IDE

Terminal First

A redesign that deletes the chrome instead of rearranging it. Layout and density copy cmux (28px bars, one 240px workspace sidebar, no status bar, one accent color); the terminal is a faithful Ghostty surface — JetBrains Mono 13 on #282c34 with the stock dark palette from this machine. Today the terminal owns 41% of the window; here it owns ~86%, and everything — terminal, file, git diff — is just a tab in one strip, like VS Code.

Default state sidebar + panes, nothing else

One workspace list (tmux sessions as rich rows: name, last agent event, branch* · cwd), one slim window-tab strip, then full-bleed terminals. Seven visible controls at rest — down from ~20. Connection state is the green dot in the host row; the "Live" banner, the pane badge, and the Active-pane block are gone. The focused pane carries a 2px accent ring; the codex pane below shows the 2.5px attention ring — the same blue as its sidebar badge.

Proportions: 240px sidebar (toggleable to 0 with ⌘B), 28px titlebar, 28px tab strip — everything else is terminal. At 1240px wide the panes get 999px ≈ 86% of the window area. Pane dividers are 1px black hairlines; splits are ⌘D / ⌘⇧D, drag-resizable, arranged by tmux's own layout.

Diff open tabs work like VS Code

The tab strip holds two kinds of tabs: terminal tabs (tmux windows) and document tabs (files, git diffs, markdown). Clicking a file in Git or the Explorer opens a document tab; the terminal is one keystroke away (⌃1). The right panel (⌥⌘B) is one 300px surface where Files ⇄ Git toggle, closed by default; the permanent commit form is gone — the message field appears only when staged files exist.

02

One strip, two kinds of tabs. The diff opens as the ± ExplorerTree.tsx tab and takes the full surface, Monaco-rendered; ⌃1 returns to the claude terminal. Git file rows in the panel are mono 11px with single-letter states — no per-row button clusters; clicking a row opens (or focuses) its diff tab, and actions live on right-click and in the palette.

Agents the Herdr model: two stacked lists

Per user direction, the agents UI copies Herdr: the sidebar splits into two sections with a draggable divider — workspaces on top, a flat agents list below, so you always see both the per-workspace view and the agent view. The agents list is global across workspaces (Herdr shipped a per-workspace scope filter and then deleted it); the only toggle is ordering, a one-word clickable control in the section header: grouped (workspace order) ⇄ priority (blocked first, then unread-done, then working — note done-but-unread outranks working: the list is an inbox). Rows are Herdr's two-line shape — state dot + workspace + tab, then agent + activity — and clicking a row switches workspace, window, and pane in one shot. States are color-coded dots: yellow working, red blocked, teal done-unread, hollow idle; a finished agent stays "done" until you focus its pane.

Priority sort shown — the inbox view. Blocked (red) leads, then done-unread (teal), then working (yellow), idle last (hollow). In grouped mode the same rows follow workspace order instead. The workspace rows above keep their aggregate state (a workspace inherits its loudest agent), so the top section answers "where is work happening" while the bottom answers "who needs me". Command palette where all the buttons went

Every removed button becomes a palette command with a real ⌘-glyph shortcut (fixing finding M10-E052 — no more Meta+Shift+P). 560px wide, 28px rows, inline group labels instead of today's repeating category column, no empty shortcut lozenges. Fuzzy workspace switching is ⌘P; the palette is ⌘K.

Design tokens

Surfaces + accent

Chrome #101114, raised #16181c, terminal #282c34 (Ghostty), accent #0091FF (cmux). Hairlines #1c1e22. One accent for selection, attention, badges, links.

Terminal palette

Ghostty Default Style Dark, verbatim: fg #ffffff, cursor white block, inverted selection, ANSI 0–15 from the theme file. Never used for chrome.

Type

Chrome: SF system font — row title 12.5 semibold, secondary 10.5, metadata 10 mono, section labels 9.5 caps. Terminal: JetBrains Mono 13 / 1.42, bundled via @font-face (replaces the unbundled Inter reference).

Metrics

All bars 28px. Sidebar 240px (min) – 1/3 window, right panel 300px default. Focus ring 2px accent, attention ring 2.5px radius 6. Palette 560×28px rows. Context menus 13px/24px rows.
