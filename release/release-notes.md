## Install / upgrade

```sh
curl -fsSL https://github.com/gal064/muxflow/releases/latest/download/install.sh | bash
```

Linux (x86_64 and aarch64) and macOS (Apple Silicon). Quit Muxflow, run the
same command to upgrade, and relaunch. tmux 3.3 or newer must be installed on
every host you attach to. For Android, sideload
`muxflow-{{VERSION}}-android.apk` below.
